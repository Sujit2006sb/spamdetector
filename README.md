# Email Spam Detector 📧

An Email Spam Detection System that helps classify emails as **Spam** or **Not Spam**.

## 🚀 Features
- Email fetching
- Spam detection
- Trusted domain management
- Email history tracking

## 🛠️ Technologies Used
- HTML
- JavaScript
- Node.js
- npm

## 📂 Project Structure
- `index.html` – User interface
- `server.js` – Backend server
- `emailFetcher.js` – Email fetching functionality
- `trustedDomains.json` – Trusted domain storage
- `history.json` – Email history
- `package.json` – Project dependencies
